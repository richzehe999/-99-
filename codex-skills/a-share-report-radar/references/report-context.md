## Current Report Purpose

The report is a daily A股盘后验证雷达. Its purpose is to compare previous message-driven theses against actual A股盘面 evidence, then update a shareable static HTML dashboard.

Core analysis format:

1. Market KPIs
2. Verification conclusion
3. Verification strength meter
4. Theme cards with filterable states
5. Sector transmission matrix
6. Linkage map
7. Buyer-perspective next-step decision cards and detail table
8. Follow-up validation checklist
9. Source links

## Source Preferences

Use current-day sources for each update. Good source types:

- 收盘/收评: 每日经济新闻, 新浪/格隆汇, 中国经济网, 证券时报, 财联社 syndications
- 科创板: 新华财经 or official exchange/data reports when available
- Funding: 东方财富, 证券时报/数据宝
- External catalysts: official company announcements first, then Reuters/Bloomberg/WSJ/MarketWatch when official source is unavailable

## Report Voice

- Direct, concise, evidence-led.
- State what changed from the previous day.
- Separate event logic from actual盘面 confirmation.
- Do not over-attribute a market move to one narrative when multiple causes are plausible.
- Do not issue buy/sell advice.
