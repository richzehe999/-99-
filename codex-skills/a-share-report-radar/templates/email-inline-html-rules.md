# A股雷达邮件 HTML 规则

自动邮件正文必须使用 email-safe inline HTML。

## 必须

- 邮件正文直接可读，作为 SMTP `text/html` 正文发送。
- 使用 `div`、`table`、`tr`、`td`、`h1`、`h2`、`p`、`span`、`a` 等基础标签。
- 所有视觉样式写在元素 `style` 属性里。
- 移动端可读，正文宽度建议 `max-width: 960px`。
- 邮件顶部必须显示报告日期和数据口径。
- 每次运行必须先获取当前日期对应的最新数据。

## 禁止

- 禁止使用 `<style>`、`<script>`、`<head>`、`<!doctype>` 或完整网页 CSS。
- 禁止直接把 `a-share-report-site/index.html` 作为邮件正文。
- 禁止把 CSS 代码块放进邮件正文。
- 禁止只发送 Markdown 或纯文本。
- 禁止把 ZIP 作为主要交付。
- 禁止复用旧报告日期、旧指数、旧成交额或旧板块结论。

## 数据新鲜度

- 盘前报告：使用运行时最新可得的隔夜外盘、商品、汇率、政策与消息数据，并承接最近一个A股交易日盘后结论。
- 盘后报告：使用当日A股收盘数据；若当日不是交易日，明确写出非交易日原因，并使用最近一个交易日作为数据口径。
- 输出前自检报告日期，报告日期不得早于目标数据口径。
